# Caption candidates

Offline generation may write new candidate tracks here. This directory is separate from `data/captions/`, which supplies the application's working track.

Candidates must pass structural, source-preservation, meaningful-variation, timing and human-review checks before study use. A JSON schema pass alone does not establish sound truth. No generated candidate has been approved or installed during the 24 October fixes. Rejected probe outputs are local evidence under ignored `artifacts/rejected-generation/`.

See [the generation tooling guide](../../scripts/generation/README.md), [caption provenance](../../docs/CAPTION_GENERATION_STATUS.md), and [model trials](../../docs/integrations/NVIDIA_MODELS.md).
